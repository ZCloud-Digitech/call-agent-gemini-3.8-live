## Short answer

- **Oru 3 nimisha outbound call (India mobile) ≈ ₹22** → ₹1000-ku **~45 calls** (~135 nimisham).
- Selavula periya pangu **Twilio** (India-ku call panna ~₹5.2/min incl. Media Streams). Gemini ~₹2.3/min.
- Testing free: Gemini free tier + Cloudflare free + Firebase free. Twilio-ku trial credit mattum.
- Suggested client price: **₹12–15/min** illa monthly plan (₹4,999-la 300 nimisham). Details 04-la.

Exchange rate assumption: **$1 = ₹96** (Sept 2026 snapshot; live rate bank/XE-la paarunga).
